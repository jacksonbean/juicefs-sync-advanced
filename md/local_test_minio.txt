# 本地 MinIO 迁移测试

## 方案概述

- 启动两个 MinIO 服务（源和目标）
- 生成测试数据（10000 个对象）
- 执行迁移测试
- 验证结果

---

## 准备工作

### 1. 安装 MinIO Client (mc)

```bash
# macOS
brew install minio-stable/mc/mc

# Linux
wget https://dl.min.io/client/mc/release/linux-amd64/mc
chmod +x mc
sudo mv mc /usr/local/bin/
```

### 2. 启动两个 MinIO 服务

```bash
#!/bin/bash
# start_minio.sh - 启动源和目标 MinIO 服务

mkdir -p /tmp/minio-src /tmp/minio-dst

# 启动源 MinIO（端口 9000）
echo "启动源 MinIO :9000 ..."
minio server /tmp/minio-src --address :9000 --console-address :9001 &
SRC_PID=$!
sleep 3

# 启动目标 MinIO（端口 9002）
echo "启动目标 MinIO :9002 ..."
minio server /tmp/minio-dst --address :9002 --console-address :9003 &
DST_PID=$!
sleep 3

# 配置 mc
mc alias set source http://127.0.0.1:9000 minioadmin minioadmin
mc alias set target http://127.0.0.1:9002 minioadmin minioadmin

# 创建 bucket
mc mb source/testbucket --quiet
mc mb target/testbucket --quiet

echo "MinIO 服务已启动"
echo "源: http://127.0.0.1:9000 (console: 9001)"
echo "目标: http://127.0.0.1:9002 (console: 9003)"
echo "用户名: minioadmin / minioadmin"
echo ""
echo "源 PID: $SRC_PID"
echo "目标 PID: $DST_PID"

# 保存 PID
echo "$SRC_PID" > /tmp/minio_src.pid
echo "$DST_PID" > /tmp/minio_dst.pid
```

## 生成测试数据

```bash
#!/bin/bash
# generate_test_data.sh - 生成 10000 个测试对象

# 创建测试文件
for i in $(seq 1 10000); do
    echo "test data $i" > "/tmp/testdata/file_$i.txt"
done

# 上传到源 MinIO
mc cp /tmp/testdata/* source/testbucket/

# 或者用 mc 命令直接生成
for i in $(seq 1 10000); do
    echo "content of file $i" | mc pipe source/testbucket/file_$i.txt
done

echo "已生成 10000 个测试对象"

# 验证
mc ls source/testbucket | wc -l
```

## 简化版：一键测试脚本

```bash
#!/bin/bash
# test_local_migration.sh - 本地 MinIO 迁移测试

echo "=========================================="
echo "  本地 MinIO 迁移测试"
echo "=========================================="

# 配置
SRC_DIR="/tmp/minio-src"
DST_DIR="/tmp/minio-dst"
SRC_PORT=9000
DST_PORT=9002
BUCKET="testbucket"
TEST_COUNT=10000

# 清理旧数据
rm -rf $SRC_DIR $DST_DIR
mkdir -p $SRC_DIR $DST_DIR

# 启动 MinIO 服务
echo ">>> 启动 MinIO 服务..."
minio server $SRC_DIR --address :$SRC_PORT --console-address :9001 > /tmp/minio_src.log 2>&1 &
SRC_PID=$!
minio server $DST_DIR --address :$DST_PORT --console-address :9003 > /tmp/minio_dst.log 2>&1 &
DST_PID=$!

sleep 3

# 配置 mc
mc alias set src http://127.0.0.1:$SRC_PORT minioadmin minioadmin > /dev/null 2>&1
mc alias set dst http://127.0.0.1:$DST_PORT minioadmin minioadmin > /dev/null 2>&1

# 创建 bucket
mc mb src/$BUCKET --quiet 2>/dev/null
mc mb dst/$BUCKET --quiet 2>/dev/null

echo ">>> 生成 $TEST_COUNT 个测试对象..."
for i in $(seq 1 $TEST_COUNT); do
    echo "test content $i" | mc pipe src/$BUCKET/test_$i.txt
done

echo ">>> 源端对象数量:"
mc ls src/$BUCKET | wc -l

# 执行迁移
echo ""
echo ">>> 开始迁移..."
START_TIME=$(date +%s)

juicefs sync \
    --ignore-existing \
    --check-new \
    --threads 20 \
    --list-threads 5 \
    --verbose \
    --metrics 127.0.0.1:9567 \
    "s3://minioadmin:minioadmin@127.0.0.1:$SRC_PORT/$BUCKET/" \
    "s3://minioadmin:minioadmin@127.0.0.1:$DST_PORT/$BUCKET/"

EXIT_CODE=$?
DURATION=$(($(date +%s) - START_TIME))

echo ""
echo ">>> 迁移完成，耗时: ${DURATION}秒"

# 验证
echo ""
echo ">>> 验证结果..."
SRC_COUNT=$(mc ls src/$BUCKET 2>/dev/null | wc -l)
DST_COUNT=$(mc ls dst/$BUCKET 2>/dev/null | wc -l)

echo "源端对象数: $SRC_COUNT"
echo "目标对象数: $DST_COUNT"

if [ $SRC_COUNT -eq $DST_COUNT ]; then
    echo "✓ 对象数量一致"
else
    echo "✗ 对象数量不一致"
fi

# 抽样验证
echo ""
echo ">>> 抽样验证..."
SAMPLE_KEY="test_1234.txt"
if mc ls dst/$BUCKET/$SAMPLE_KEY > /dev/null 2>&1; then
    echo "✓ 样本文件 $SAMPLE_KEY 存在"
else
    echo "✗ 样本文件 $SAMPLE_KEY 不存在"
fi

# 清理
echo ""
echo ">>> 清理测试环境..."
kill $SRC_PID $DST_PID 2>/dev/null
rm -rf $SRC_DIR $DST_DIR

echo ""
echo "=========================================="
echo "  测试完成"
echo "=========================================="
```

## 手动执行步骤

### 1. 启动 MinIO

```bash
# 终端1：启动源 MinIO
minio server /tmp/minio-src --address :9000 --console-address :9001

# 终端2：启动目标 MinIO
minio server /tmp/minio-dst --address :9002 --console-address :9003
```

### 2. 配置 mc

```bash
mc alias set src http://127.0.0.1:9000 minioadmin minioadmin
mc alias set dst http://127.0.0.1:9002 minioadmin minioadmin
mc mb src/testbucket
mc mb dst/testbucket
```

### 3. 生成测试数据

```bash
# 生成 10000 个文件
for i in $(seq 1 10000); do
    echo "test $i" | mc pipe src/testbucket/file_$i.txt
done
```

### 4. 执行迁移

```bash
juicefs sync \
    --ignore-existing \
    --check-new \
    --threads 20 \
    --verbose \
    s3://minioadmin:minioadmin@127.0.0.1:9000/testbucket/ \
    s3://minioadmin:minioadmin@127.0.0.1:9002/testbucket/
```

### 5. 验证

```bash
# 查看源和目标数量
mc ls src/testbucket | wc -l
mc ls dst/testbucket | wc -l
```

---

## 注意事项

1. **MinIO 访问密钥**：示例使用 `minioadmin:minioadmin`，生产环境请更换
2. **URL 编码**：密钥中的特殊字符需要 URL 编码（如 `/` 编码为 `%2F`）
3. **JuiceFS 需要最新版本**：确保安装最新版的 juicefs

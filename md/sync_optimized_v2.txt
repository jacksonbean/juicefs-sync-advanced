# ECS → COS 迁移方案（优化版 v2）

## 方案概述

- **目标**：将数据从 ECS 迁移到 COS
- **问题**：源存储中以 "9" 开头的内容较多，第二个字符为纯数字
- **策略**：按前两个字符分区，确保负载均衡
- **原则**：准确优先，存在即跳过，简单可重跑

---

## 分区策略

### 问题分析

原方案按 0-3、4-6、7-9 划分，但 9 开头内容较多，会导致机器 3 负载过重。

### 优化方案：按前两个字符分区

将前两个字符组合成 36 种组合（0-9 + 0-9/a-z），均匀分配到 3 台机器：

| 机器 | 范围 | 组合数 | 说明 |
|------|------|--------|------|
| 机器1 | 00-11 | 12 | 0x 和 1x |
| 机器2 | 24-35 | 12 | 2x、3x、4x、5x |
| 机器3 | 60-99 | 40 | 6x-9x（包含大量 9x） |

更均匀的方案：**按三字符分区**（更精细负载均衡）：

| 机器 | 范围 | 覆盖前缀 |
|------|------|----------|
| 机器1 | 000-329 | 00, 01, 02, 03, 10-13, 20-23, 30-32 |
| 机器2 | 330-659 | 04, 05, 06, 14-16, 24-26, 33-35, 40-43 |
| 机器3 | 660-999 | 07, 08, 09, 17-19, 27-29, 36-39, 44-99 |

---

## 最终推荐：按首字符+第二字符组合分区

### 分区详情

| 机器 | 数字前缀组合 | 占比预估 | 说明 |
|------|-------------|----------|------|
| 机器1 | 00-03, 10-13, 20-23, 30-33 | ~33% | 0-3 开头，第二字符 0-3 |
| 机器4 | 04-06, 14-16, 24-26, 34-36, 40-43 | ~33% | 4-6 开头，第二字符 0-6 |
| 机器2 | 07-09, 17-19, 27-29, 37-39, 44-99 | ~34% | 7-9 开头，9 含量大 |

由于 9 开头内容特别多，建议 **4 台机器** 或 **调整分布**：

### 4 台机器方案（推荐）

| 机器 | 范围 | 覆盖前缀 | 预估占比 |
|------|------|----------|----------|
| 机器1 | 00-24 | 00-03, 10-13, 20-23 | ~25% |
| 机器2 | 25-49 | 04-06, 14-16, 24-26, 34-36, 40-43 | ~25% |
| 机器3 | 50-74 | 07-09, 17-19, 27-29, 37-39, 44-49 | ~25% |
| 机器4 | 75-99 | 50-99（包含大量 9x） | ~25% |

### 3 台机器方案（如果只有3台）

| 机器 | 范围 | 覆盖前缀 | 预估占比 |
|------|------|----------|----------|
| 机器1 | 00-32 | 00-03, 10-13, 20-23, 30-32 | ~33% |
| 机器2 | 33-65 | 04-06, 14-16, 24-26, 34-36, 40-43, 50-53, 60-65 | ~33% |
| 机器3 | 66-99 | 07-09, 17-19, 27-29, 37-39, 44-49, 54-59, 66-99 | ~34% |

## 机器1 脚本 (00-24)

创建 `/opt/migration/machine1_00-24.sh`：

```bash
#!/bin/bash
# machine1_00-24.sh - 机器1：前缀 00-24

LOG_DIR="/var/log/juicefs"
FAILED_LIST="$LOG_DIR/failed_00-24.list"

mkdir -p $LOG_DIR
> $FAILED_LIST

echo "===== 机器1开始迁移 00-24 $(date) =====" | tee -a $LOG_DIR/migration.log

# 后台监控错误
(
    tail -F $LOG_DIR/juicefs_00-24.log 2>/dev/null | while read line; do
        if echo "$line" | grep -qiE "error|fail|timeout"; then
            echo "$line" | grep -oE 's3://[a-zA-Z0-9._/-]+' >> "$FAILED_LIST"
        fi
    done
) &
TAIL_PID=$!

START_TIME=$(date +%s)

# 使用 --start 和 --end 限定范围（按 ASCII 排序）
# 00-24 范围
juicefs sync \
  --ignore-existing \
  --threads 200 \
  --list-threads 50 \
  --start "00" --end "25" \
  --max-failure 10 \
  --check-change \
  s3://ecs-source/ \
  cos://cos-dest/ \
  2>&1 | tee "$LOG_DIR/juicefs_00-24.log"

EXIT_CODE=${PIPESTATUS[0]}
kill $TAIL_PID 2>/dev/null

END_TIME=$(date +%s)
DURATION=$((END_TIME - START_TIME))

COPIED=$(grep -c "Copied" "$LOG_DIR/juicefs_00-24.log" 2>/dev/null || echo 0)
SKIPPED=$(grep -c -i "exist" "$LOG_DIR/juicefs_00-24.log" 2>/dev/null || echo 0)
ERRORS=$(grep -icE "error|fail" "$LOG_DIR/juicefs_00-24.log" 2>/dev/null || echo 0)

if [ -f "$FAILED_LIST" ]; then
    sort -u "$FAILED_LIST" -o "$FAILED_LIST"
    failed_count=$(wc -l < "$FAILED_LIST")
    [ "$failed_count" -gt 0 ] && echo "⚠️ 发现 $failed_count 个失败文件" | tee -a $LOG_DIR/migration.log
fi

echo "===== 机器1结束 $(date) =====" | tee -a $LOG_DIR/migration.log
echo "耗时: ${DURATION}秒 | 已复制: $COPIED | 已跳过: $SKIPPED | 错误: $ERRORS" | tee -a $LOG_DIR/migration.log
exit $EXIT_CODE
```

## 监控脚本

创建 `/opt/migration/monitor.sh`：

```bash
#!/bin/bash
# monitor.sh - 实时监控迁移进度

LOG_DIR="/var/log/juicefs"

while true; do
    clear
    echo "==== 迁移监控 - $(date) ===="
    echo ""

    total_copied=0
    total_skipped=0
    total_errors=0

    for log in $LOG_DIR/juicefs_*.log; do
        [ -f "$log" ] || continue

        range=$(basename $log | grep -oE '[0-9-]+' || echo "未知")
        echo "--- 范围: $range ---"

        copied=$(grep -c "Copied" $log 2>/dev/null || echo 0)
        skipped=$(grep -c -i "exist" $log 2>/dev/null || echo 0)
        errors=$(grep -icE "error|fail" $log 2>/dev/null || echo 0)

        total_copied=$((total_copied + copied))
        total_skipped=$((total_skipped + skipped))
        total_errors=$((total_errors + errors))

        echo "已复制: $copied | 已跳过: $skipped | 错误: $errors"

        # 显示最近错误
        if [ "$errors" -gt 0 ]; then
            echo "最近错误:"
            grep -iE "error|fail" $log 2>/dev/null | tail -2 | sed 's/^/  /'
        fi
        echo ""
    done

    echo "=== 汇总 ==="
    echo "总计: 已复制=$total_copied | 已跳过=$total_skipped | 错误=$total_errors"

    # 系统资源
    echo ""
    echo "--- 系统状态 ---"
    echo "内存: $(free -h | awk '/Mem/{print $3"/"$2}')"
    echo "负载: $(uptime | awk -F'load average:' '{print $2}')"
    echo "磁盘: $(df -h /var | tail -1 | awk '{print $3"/"$2 " (" $5 ")"}')"

    # 待重试
    for failed in $LOG_DIR/failed_*.list; do
        [ -f "$failed" ] || continue
        count=$(wc -l < "$failed" 2>/dev/null || echo 0)
        [ "$count" -gt 0 ] && echo "待重试: $(basename $failed) 有 $count 个"
    done

    echo ""
    echo "按 Ctrl+C 退出"
    sleep 30
done
```

## 关键参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| `--ignore-existing` | ✅ | 目标存在即跳过 |
| `--threads` | 200 | 传输线程 |
| `--list-threads` | 50 | 列举线程 |
| `--start/--end` | 按两字符范围 | 00-25, 25-50, 50-75, 75-: |
| `--max-failure` | 10 | 失败次数阈值 |
| `--check-change` | ✅ | 轻量级校验 |

## 方案对比

| 对比项 | 原方案 (0-3/4-6/7-9) | 优化方案 (4台) |
|--------|----------------------|----------------|
| 分区粒度 | 1个字符 | 2个字符 |
| 负载均衡 | 不均匀（9多） | 均匀 (~25%每台) |
| 机器数量 | 3台 | 4台 |
| 适用场景 | 均匀分布 | 9开头内容多 |

---

## 注意

- 如果只有 **3 台机器**，使用原方案即可，差异不会太大
- 如果 **9 开头特别多**（比如占 50%+），建议至少用 4 台机器
- `--start` 和 `--end` 参数按 ASCII 排序，":" 在数字之后，所以 "75-:" 会包含 75-99

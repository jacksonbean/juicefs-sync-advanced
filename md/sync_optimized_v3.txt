# ECS → COS 迁移方案（优化版 v3 - 精细分区）

## 方案概述

- **目标**：将数据从 ECS 迁移到 COS
- **问题**：9 开头内容特别多，第二个字符是数字
- **策略**：将 90-99 范围细分成两组，分散负载

---

## 分区方案（6台机器）

| 机器 | 范围 | 覆盖前缀 | 预估占比 |
|------|------|----------|----------|
| 机器1 | 00-16 | 00-16 | ~17% |
| 机器2 | 17-33 | 17-33 | ~17% |
| 机器3 | 34-50 | 34-50 | ~17% |
| 机器4 | 51-66 | 51-66 | ~17% |
| 机器5 | 67-89 | 67-89 | ~23%（7-8开头） |
| 机器6 | 90-95 | 90-95 | ~5%（9开头前半） |
| 机器7 | 96-99 | 96-99 | ~4%（9开头后半） |

如果只有 **5 台机器**：

| 机器 | 范围 | 覆盖前缀 | 预估占比 |
|------|------|----------|----------|
| 机器1 | 00-19 | 00-19 | ~20% |
| 机器2 | 20-39 | 20-39 | ~20% |
| 机器3 | 40-59 | 40-59 | ~20% |
| 机器4 | 60-79 | 60-79 | ~20%（6-7开头） |
| 机器5 | 80-99 | 80-99 | ~20%（8-9开头，9多） |

## 机器1 脚本 (00-19)

```bash
#!/bin/bash
# machine1_00-19.sh - 机器1：前缀 00-19

LOG_DIR="/var/log/juicefs"
FAILED_LIST="$LOG_DIR/failed_00-19.list"

mkdir -p $LOG_DIR
> $FAILED_LIST

echo "===== 机器1开始迁移 00-19 $(date) =====" | tee -a $LOG_DIR/migration.log

(
    tail -F $LOG_DIR/juicefs_00-19.log 2>/dev/null | while read line; do
        if echo "$line" | grep -qiE "error|fail|timeout"; then
            echo "$line" | grep -oE 's3://[a-zA-Z0-9._/-]+' >> "$FAILED_LIST"
        fi
    done
) &
TAIL_PID=$!

START_TIME=$(date +%s)

juicefs sync \
  --ignore-existing \
  --threads 200 \
  --list-threads 50 \
  --start "00" --end "20" \
  --max-failure 10 \
  --check-change \
  s3://ecs-source/ \
  cos://cos-dest/ \
  2>&1 | tee "$LOG_DIR/juicefs_00-19.log"

EXIT_CODE=${PIPESTATUS[0]}
kill $TAIL_PID 2>/dev/null

DURATION=$(($(date +%s) - START_TIME))
COPIED=$(grep -c "Copied" "$LOG_DIR/juicefs_00-19.log" 2>/dev/null || echo 0)
SKIPPED=$(grep -c -i "exist" "$LOG_DIR/juicefs_00-19.log" 2>/dev/null || echo 0)
ERRORS=$(grep -icE "error|fail" "$LOG_DIR/juicefs_00-19.log" 2>/dev/null || echo 0)

[ -f "$FAILED_LIST" ] && sort -u "$FAILED_LIST" -o "$FAILED_LIST"

echo "===== 机器1结束 $(date) =====" | tee -a $LOG_DIR/migration.log
echo "耗时: ${DURATION}秒 | 已复制: $COPIED | 已跳过: $SKIPPED | 错误: $ERRORS" | tee -a $LOG_DIR/migration.log
exit $EXIT_CODE
```

## 监控脚本

```bash
#!/bin/bash
# monitor.sh - 实时监控迁移进度

LOG_DIR="/var/log/juicefs"

while true; do
    clear
    echo "==== 迁移监控 - $(date) ===="
    echo ""

    total_copied=0
    total_skipped=0
    total_errors=0

    for log in $LOG_DIR/juicefs_*.log; do
        [ -f "$log" ] || continue

        range=$(basename $log | grep -oE '[0-9-]+' || echo "未知")
        echo "--- 范围: $range ---"

        copied=$(grep -c "Copied" $log 2>/dev/null || echo 0)
        skipped=$(grep -c -i "exist" $log 2>/dev/null || echo 0)
        errors=$(grep -icE "error|fail" $log 2>/dev/null || echo 0)

        total_copied=$((total_copied + copied))
        total_skipped=$((total_skipped + skipped))
        total_errors=$((total_errors + errors))

        echo "已复制: $copied | 已跳过: $skipped | 错误: $errors"
        echo ""
    done

    echo "=== 汇总 ==="
    echo "总计: 已复制=$total_copied | 已跳过=$total_skipped | 错误=$total_errors"

    echo ""
    echo "--- 系统状态 ---"
    echo "内存: $(free -h | awk '/Mem/{print $3"/"$2}')"
    echo "负载: $(uptime | awk -F'load average:' '{print $2}')"

    for failed in $LOG_DIR/failed_*.list; do
        [ -f "$failed" ] || continue
        count=$(wc -l < "$failed" 2>/dev/null || echo 0)
        [ "$count" -gt 0 ] && echo "待重试: $(basename $failed) 有 $count 个"
    done

    echo ""
    echo "按 Ctrl+C 退出"
    sleep 30
done
```

## 方案总结

| 机器数 | 分区方式 | 特点 |
|--------|----------|------|
| 5台 | 00-19, 20-39, 40-59, 60-79, 80-99 | 简单，80-99 负载稍大 |
| 6台 | 00-16, 17-33, 34-50, 51-66, 67-89, 90-99 | 更均衡，9开头单独一组 |

如果 9 开头特别多，建议用 **6 台机器**，把 90-99 单独分开。
